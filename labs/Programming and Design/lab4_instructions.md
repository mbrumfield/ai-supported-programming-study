Grade calculator lab instructions
=================================

Create a web app that asks the user to select a course and enables the user to
enter five test scores for that course. Allow only scores between 0 and 100. The
program displays the average score and the resulting letter grade. Include a
reset button which clears all selections.

Available courses:

* CSC 221 - Fundamentals of Programming I
* MAT 131 - College Algebra
* BIO 111 - General Biology

The grading scale is as follows:

* 90 - 100 = A
* 80 - 89 = B
* 70 - 79 = C
* 60 - 69 = D
* Below 60 = F

Pre-lab
-------

1. Open an online Markdown editor, then load the lab template:
   1. Open [StackEdit](https://stackedit.io/app#), then delete all text in the
      editor. <mark>Perhaps use [https://edtr.md/app](https://edtr.md/app)? BAJ
      thoughts: Pros: there's a nice open file capability that means students
      don't have to copy and paste text in. Cons: it doesn't sync the left and
      right panes like StackEdit does. I like StackEdit a bit better because I
      think sync will help students see the effects of their edits, but it's not
      a large advantage.</mark>
   2. Browse to the
      [grade calculator lab template](https://raw.githubusercontent.com/mbrumfield/ai-supported-programming-study/refs/heads/main/labs/Programming%20and%20Design/Lab4_instructions.cpp);
      select all the text in this document then copy it.
   3. Paste this copied text into StackEdit. StackEdit uses Markdown; this
      [guide](https://commonmark.org/help/) shows how formatting in Markdown
      works.
2. Complete the "Pre-lab activities" subsection of the template.

Lab procedure
-------------

1. Fill in the missing information in the lab template to create a specification
   for your program.
3. Improve your specification:
   1. Review a partner's specification while they review your specification.
      Discuss the differences, and find ways to improve both your
      specifications.
   2. Browse to [Gemini](https://gemini.google.com/app), paste the plain text of
      your specification in from the left-hand side of StackEdit, then press
      enter.
   3. Modify this document based on the problems identified. Don't adopt every
      suggestion; decide which suggestions are relevant. Record which round of
      review, how many findings Gemini identified, a short, one-sentence summary
      of the changes you made, and an explanation of any rejected suggestions in
      the review rounds table below.
   4. Repeat steps 2.2-2.3 until the problems identified are trivial or
      contradictory. Paste the last review from Gemini into the matching section
      below.
4. Implement your program:
   1. Edit the first line of the specification: change it from "Review this
      specification" to "Implement this specification."
   2. Copy and paste the plain text into
      [Gemini Canvas](https://gemini.google.com/canvas). This transforms your
      specification into JavaScript code then shows the resulting web app.
   3. Test the resulting app: does it perform as expected? If there are bugs,
      update this specification then re-generate the app.

Post-lab
--------

1. Look at the code produced by your implementation. Use this to fill in the
   "Code concept identification" section of your specification.
2. Submit your specification and a screenshot of the resulting implementation to
   Canvas.
